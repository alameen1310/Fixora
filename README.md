# Fixora

Fixora is a household-services marketplace concept built around discovering real household problems and skilled professionals. The repository currently contains the frontend foundation only; product pages, marketplace workflows, authentication, and backend integrations have not been implemented.

## Run locally

```sh
npm install
npm run dev
```

## Build, lint, and preview

```sh
npm run build
npm run lint
npm run preview
```

The frontend uses React, Vite, JavaScript/JSX, and global CSS tokens. See `ABOUT.md` for product direction and `DESIGN.md` for visual guidance.
